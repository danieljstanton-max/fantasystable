Launching Online Casinos Africa

Three uploads, one import, and one migration that has to be done in the right order or two indexed URLs go dark. About ninety minutes end to end, most of it in phase four.

Before you start

Two of these take minutes and save an hour of confusion later.

  1. Take a backup Hostinger › hPanel › Backups

    Phase 3 involves trashing two published pages. A restore point makes that reversible rather than final.

  2. Confirm Elementor Pro is active Plugins

    Free Elementor cannot build templates for custom post types or read custom fields. Without Pro, the plugin still works and you would build the country pages with shortcodes instead — but Theme Builder is the route this runbook assumes.

  3. Note what is currently live

    Exactly two pages: /online-casinos-nigeria/ and /online-casinos-kenya/. Everything else on the domain is new. Those two are the only ranking signal you currently hold, which is why phase 3 is the careful one.

1

Install

Order matters here too: the parent theme must exist before its child can activate.

  1. Install Hello Elementor — do not activate it Appearance › Themes › Add New

    Search for it, click Install, and stop. It is the parent; activating it directly would give you an unstyled site.

  2. Upload and activate oca-brand.zip Appearance › Themes › Add New › Upload

    This replaces Astra. Leave Astra installed — switching back is one click if anything looks wrong.

  3. Upload and activate oca-core.zip Plugins › Add New › Upload

    On activation it registers the post types and flushes the rewrite rules, so the country URLs resolve immediately.

  4. Check the site loads

    You should see a white page in Mattone and Manrope with the lion. If the fonts look wrong, the theme did not activate — check that Hello Elementor is installed.

If anything errors on activation, stop and send me the message. I have never been able to run this PHP — there is no PHP runtime on your Mac, so every file has been checked by hand rather than executed. The likeliest failure point is the Elementor dynamic-tag classes, which depend on Pro's class names being where I expect them.
2

Import the content

Ten countries and forty-six operators, in one click.

  1. Run the importer Countries › Import countries

    Leave Publish immediately unticked. Everything arrives as drafts so you can read it before it goes live. Running it twice is safe — anything that already exists is updated, never duplicated.

  2. Read what it warns you about

    The screen lists the two URLs currently held by existing pages, and the three things the import cannot supply: logos, real affiliate links, and licence verification dates.

  3. Spot-check two pages

    Open Kenya and Egypt. Kenya should carry five operators and a full legal section; Egypt should carry none and say why. If Egypt shows operators, something has gone wrong with the import.

3

Migrate the two live URLs

The only step that can cost you something you already have.

Do this in exactly this order

Country posts resolve at /online-casinos-{slug}/, which is byte-identical to your two live URLs. That means no redirects are needed — but it also means the old page and the new post want the same address, and WordPress will serve the page and never reach the post.

  1. Publish the imported Kenya country post. Its slug must be kenya, bare — the plugin adds the prefix itself.
  2. Copy anything worth keeping from the old page into it.
  3. Only now move the old page to trash.
  4. Load /online-casinos-kenya/ and confirm the new page appears.
  5. Repeat for Nigeria.

Done in this order the URL is never dark. Done in the other order — trashing first — you have a 404 sitting on one of your only two indexed pages for as long as it takes you to notice.

If a country page 404s at any point: Settings › Permalinks › Save Changes. You do not need to change anything; saving rebuilds the rewrite rules. This is the single most common cause and takes five seconds to rule out.
4

Build the two templates

One country template and one casino template. Ten pages and forty-six reviews then render themselves.

  1. Create a Single template for Country Templates › Theme Builder › Single › Add New

    Set the condition to Countries. Build the layout once; every country uses it.

  2. Pull fields in with dynamic tags

    Click the small database icon beside almost any Elementor control. Under Online Casinos Africa you will find OCA field for any text, number, date or dropdown, and OCA link for the affiliate URL on a button.

    The Format control on OCA field renders dates as “27 August 2026” rather than 2026-08-27, and dropdowns as their label rather than their stored key.

  3. Drop the repeating blocks in as shortcodes

    Use an Elementor Shortcode widget. Building a five-row payment table by hand ten times is exactly the work worth avoiding — and a payout time corrected once should correct everywhere.

  4. Repeat for Casino

    Same process, condition set to Casinos.

  5. Set the global fonts and colours Elementor › Site Settings

    Global Fonts: Primary Mattone, Secondary Manrope. Both are already loaded, so they appear in the family list. Global Colors: paste the values from oca-brand/assets/css/brand.css.

When it goes wrong

The four failures I would expect, and what each one actually is.

A country page returns 404
Settings › Permalinks › Save Changes. The rewrite rules did not flush. Saving rebuilds them without changing anything. This accounts for most 404s on a fresh install and takes five seconds to rule out.
The old page still shows at /online-casinos-kenya/
The page is still published and WordPress serves it in preference to the post. Trash the page — but only after the country post is published and its content is across.
No “Online Casinos Africa” group in the dynamic tags
Elementor Pro is not active. Free Elementor has no dynamic-tag UI, so the tags register harmlessly and never appear. Either activate Pro, or build the country pages with the shortcodes instead — they need no Pro features.
A casino does not appear in any list
It has no rating. This is deliberate: nothing gets ranked before it has been assessed. Set a rating on the operator screen and it appears. The live preview on that screen tells you what else is still missing.
Fatal error on plugin activation
Send me the message and the file and line. Nothing here has been executed — only brace-checked and audited for escaping — so a PHP error is the one thing I genuinely cannot rule out. Deactivate via Hostinger’s file manager by renaming the oca-core folder if the admin locks you out.

Not covered here: the eight country pages beyond Kenya and Nigeria need no migration — they are new URLs and can simply be published. Egypt deliberately lists no operators; that is a decision, not an omission.
